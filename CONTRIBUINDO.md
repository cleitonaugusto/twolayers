# Contribuindo

Sugestões e relatos de erro são bem-vindos por *issue*.

Para aceitar código de terceiros, o projeto pede, antes do *merge*, uma **cessão de direitos autorais** sobre a
contribuição (ou licença equivalente) ao titular do projeto, para que todo o código continue sob um único titular e
o licenciamento do projeto possa ser mantido de forma coerente.
